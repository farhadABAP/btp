Step 1: Insert Data using a Console Class

We will write a quick script (just like your Hello World class) to push some orders into the table.

1. Right-click your Z_TRIAL package -> New > ABAP Class.
2. Name: ZCL_INSERT_TEST_DATA
3. Description: Insert Test Data
4. Click Next > Finish.
5. Replace all the code in the editor with this:

```abap
CLASS zcl_insert_test_data DEFINITION
  PUBLIC
  FINAL
  CREATE PUBLIC .

  PUBLIC SECTION.
    INTERFACES if_oo_adt_classrun.
ENDCLASS.

CLASS zcl_insert_test_data IMPLEMENTATION.
  METHOD if_oo_adt_classrun~main.
    " 1. Delete any old data so we start fresh
    DELETE FROM ztrial_orders.

    " 2. Insert new data
    INSERT ztrial_orders FROM TABLE @(
      VALUE #(
        ( client = sy-mandt order_id = 1 customer_name = 'Alice'   order_date = '20261025' amount = '150.50' )
        ( client = sy-mandt order_id = 2 customer_name = 'Bob'     order_date = '20261026' amount = '99.99'  )
        ( client = sy-mandt order_id = 3 customer_name = 'Charlie' order_date = '20261027' amount = '250.00' )
      )
    ).

    " 3. Output a success message
    out->write( |Data successfully inserted! { sy-dbcnt } rows created.| ).
  ENDMETHOD.
ENDCLASS.
```

6. Press Ctrl + S (Save) and Ctrl + F3 (Activate).
7. Right-click in the code editor -> Run As > 1 ABAP Application (Console).

You should see "Data successfully inserted! 3 rows created." at the bottom.

Step 2: Preview the CDS View

Now for the magic of CDS:

1. Go back to your CDS view ZI_TRIAL_ORDERS (double-click it in the project explorer on the left).
2. Right-click anywhere inside the CDS view code editor.
3. Select Open With > Data Preview (or look for the "Data Preview" icon in the top menu bar).

You should see a table pop up showing Alice, Bob, and Charlie! Let me know when you see them!
